# Create Jam Fall 2026 in BQN

To install, first install CBQN v0.12 [on linux/mac](https://github.com/dzaima/CBQN) or
[on windows](https://github.com/vylsaz/cbqn-win-docker-build/releases/tag/cbqn-0.12.0) (For windows, you should also
[add BQN to PATH](https://www.computerhope.com/issues/ch000549.htm)), then run
```
git clone --recurse-submodules https://github.com/Brian-ED/create-jam-fall-2026-BQN
cd create-jam-fall-2026-BQN
bqn rayed-bqn/install-raylib.bqn
```

To run the game, run:
```
bqn src/main.bqn
```

# Rick the Rocked Rolling Rock
Controls:
- Press any
  keyboard button
  at the right
  time to get a speed boost.
  Don't let the walls slow
  you down!
- Also, to restart,
  wait for game over
  and press
  any keyboard
  button.

The game is underdeveloped and unfinished, but you can roll and hit walls and die if you slow down from walls too much.

Speed up by pressing a keyboard key while the white line is on the red triangle.

The accumulated trash on the boulder does nothing.
